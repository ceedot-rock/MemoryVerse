# DEMO.md — under-3-minute video shot list

Total target: ~2:30. One voice, warm. No jargon.

## Shot 1 — The why (0:00–0:25)
"My dad's memory isn't what it used to be. A doctor's instruction, a name,
something for Thursday — by evening it's gone. So we built him Remember:
speak a thought, it's kept. Ask about it later, it answers."

## Shot 2 — Keeping a memo (0:25–1:00)
Terminal or web page. Type (or show an audio file):
`remember note "doctor appointment thursday at three"`
Show: "kept. (October 9, 2026 at 5:19 AM)" — point out the timestamp.
Add a second memo about the plumber.

## Shot 3 — Asking (1:00–1:40)
`remember search "doctor"`
Show the answer coming back with date and time. Say the line:
"That's the whole product. He asks in his own words, it answers."

## Shot 4 — Readback (1:40–2:10)
`remember readback`
Show the day's memos read back in order. Open the web page
(http://localhost:8077) — big buttons, big text: "this is what he sees."

## Shot 5 — The honest close (2:10–2:30)
"Everything runs on his machine — his words never leave it. And it's built
for the Bee era: the day a wearable hears his day, this is the memory it
should keep. Local, private, his."

## What NOT to show
- Don't pretend Bee hardware is involved — the vision slide is concept only.
- Don't show the mock transcriber; either install whisper for the demo or
  use typed notes and say so.
