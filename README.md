# MemoryVerse

The Mind of the Slid Phi machine: memory that persists, seals, and
proves its own provenance. What was spoken stays spoken — timestamped,
crash-safe, and attributable.

| Part | Path | What it is |
|---|---|---|
| pmcp | `pmcp/` | Persistent Memory Core Processing: compute-in-persistent-memory runtime with a deterministic extent ISA, crash-safe journal, and Chamber-signed provenance. |
| json-chamber-sdk | `json-chamber-sdk/` | Chamber: JSON sealing with φ-split keyword shares. |
| remember | `remember/` | Voice-first memory journal: speak a memory, it's captured and timestamped; ask what you said, it answers. |

## Provenance

Fused from three repos with full history preserved (merge commits, not
squashes), all from `main`.
